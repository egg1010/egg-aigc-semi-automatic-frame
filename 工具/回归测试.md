# 回归测试（REGRESSION）

**定位**：系统性回归的固定流程——修改任何规则文件（规范/模块/格式 .md/.txt）或校验器后执行，防止「改一处、坏一处」。
**依据**：审查整改 P1-06。分两层：**确定性结构验证**（校验器自动）＋**质量评价**（人工/模型辅助）。

## 测试环境

- **独立测试工作区**（目录 `回归测试工作区/`）：不进生产工作区、不进本仓库；内部结构与生产一致（剧本/集文件夹/资产图/资产表）
- **结果保存**：`回归结果/YYYY-MM-DD-场景名.md`（存于测试工作区），记录：输入快照说明｜执行命令｜输出摘要｜模型版本｜成本
- **用例素材**：短剧本、长剧本、道具传递、时间线倒叙、缺图模式、风格重构、规范缺失——优先复用用户自有（脱敏后）；敏感内容不入库

## 场景矩阵（改动后至少跑 A 组（确定性），B 组（质量）抽查）

| 编号 | 场景 | 输入准备 | 执行 | 检查 | 通过标准 |
|---|---|---|---|---|---|
| A1 | 短剧本全流程 | 单集小剧本（3-5 段） | 全局调度器 全流程（asset_reference） | 各阶段校验器 check + 人工抽读 1 段 | 0 ERROR；穿防五项无矛盾 |
| A2 | 缺图模式 | 单集剧本，无资产图 | 全流程选「暂不补全」（text_only） | check --stage VIDEO_PROMPTS_READY；详细度抽查 | 不因缺图终止；详细度不降级 |
| A3 | 规范缺失优先级 | 删除 自定义拆分格式规范.txt / 多集要求.txt | 文本模块运行 | 行为对照 跟新规范 规范清单 | optional 缺失不终止；required 缺失终止 |
| A4 | 状态与恢复 | 跑到 SCRIPT_PARSED 后中断 | init / advance / check | 断点续跑 | 跳过已完成阶段，只重跑受影响阶段 |
| B1 | 长剧本（多集） | 2 集以上剧本 | 全流程 | 跨集连续性（台账 end_state） | 段尾交接状态可用；无跨段引用 |
| B2 | 道具传递 | 含道具转移的段落 | 视频模块 | 逐镜道具行 + 台账 prop_hold | 状态变化有动作支撑，无凭空出现/消失 |
| B3 | 时间线倒叙 | 含闪回剧本 | 全流程 | 时间线 facts | UNKNOWN 不编造；闪回标记 |
| B4 | 风格重构 | 已生成提示词 | 设计与重构（普通/联动/内容） | 差异清单输出；版本防护 | 越权改动 = 0；内容改动有授权来源 |

## 指标（定期统计，改前/改后对比）

| 指标 | 统计方法 | 目标 |
|---|---|---|
| 流程完成率 | 成功通过全部必需阶段的任务占比 | ↑ |
| Schema 通过率 | 校验器 0 ERROR 的输出占比 | = 100% |
| 恢复成功率 | 中断后无需从头重做的任务占比 | ↑ |
| 资产连续性错误率 | 每百镜头人物/道具/场景状态冲突数 | ↓ |
| 事实忠实度 | 关键事实保留比例（人工抽查） | = 100% |
| 生成成本 | 每镜头 token／API 调用／人工修订时间 | ↓ |

## 执行纪律

- 规则文件或校验器改动后 → **必须跑 A 组**；校验器自身改动 → 先跑 `selftest` 再跑 A 组
- 结果必须留档（含改前/改后对比）；发现退化 → 按 `规范/异常设计.md` 处理并回滚/修复
- 回归只验证「不退化」，不追求全自动：质量类指标允许人工/模型辅助评价
