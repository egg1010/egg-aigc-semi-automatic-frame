# 校验器（VALIDATOR）

**定位**：轻量执行/校验层的落地实现——状态转移（init / advance）+ 结构校验（check）。纯 Python 标准库，无第三方依赖；**只写状态文件，不写业务交付物**。
**契约依据**：`规范/数据契约.md`（字段规则）、`规范/流程状态机.md`（阶段与门禁）；检查项清单 `python 工具/校验器.py checks`。

## 运行方式

从**框架根目录**执行（<工作区> 为待检项目目录，可用绝对路径）：

```text
初始化状态      python 工具/校验器.py init    <工作区> --unit 第1集
阶段推进        python 工具/校验器.py advance <工作区> --unit 第1集 --stage SCRIPT_PARSED --artifact segments=第1集/
声明视频模式    python 工具/校验器.py advance <工作区> --unit 第1集 --stage VIDEO_PROMPTS_READY --mode asset_reference
台账事实        python 工具/校验器.py fact    <工作区> --unit 第1集 --id 第1集.ARES.costume --value "黑铜胸甲" --source 剧本:1-2 --subject 人物:ARES --field costume [--verified]
失败记录        python 工具/校验器.py fail    <工作区> --unit 第1集 --reason "缺资产图" --action 挂起
门禁校验        python 工具/校验器.py check   <工作区> --stage VIDEO_PROMPTS_READY --unit 第1集
校验项清单      python 工具/校验器.py checks
自检            python 工具/校验器.py selftest
```

- 省略子命令时按 check 处理（首个参数=工作区）：`python 工具/校验器.py <工作区> --stage SCRIPT_PARSED`
- `check` 支持 `--json` 机器输出；退出码：0=无 ERROR｜1=有 ERROR｜2=用法/环境错误
- Python 3.8+；Windows/Linux 均可；中文文件名与 UTF-8/GBK 编码自动兼容

## 检查项（详见 `checks` 输出与 数据契约.md）

| 编号 | 级别 | 内容 |
|---|---|---|
| DS-01/02/03 | ERROR/WARN | 状态文件结构（stage、枚举、facts 字段）、记录产物存在性 |
| WS-01/02/03 | ERROR/WARN | 单元文件夹、分段文本、资产图目录 |
| AT-01/02 | ERROR/WARN | 资产表存在性与 场景/人物/道具 分区 |
| P-01～P-08 | ERROR/WARN | 提示词：槽位完整性、字数上限、图片引用、跨段引用、站位图字样、镜头编号、负面提示词、槽位顺序 |
| GATE-01/02 | ERROR | 阶段必需产物、模式一致性（asset_reference 但无图） |

## 配置（`校验配置.json`）

放在工作区根目录即可生效（或 `--config` 指定）；常用项：

```json
{
  "char_limit": 9950,
  "asset_table_patterns": ["资产表"],
  "prompt_name_include": "提示词",
  "cross_ref_error": ["与第\\s*\\d+\\s*段一致", "同第\\s*\\d+\\s*段", "同链"]
}
```

- `char_limit`：字数上限，默认 9950（对齐 基础格式 注意事项 7）；**项目另有更严上限时在此收紧**（如 `"char_limit": 9900`）
- `cross_ref_error` / `cross_ref_warn`：跨段引用禁令的匹配模式（默认见脚本内 `DEFAULT_CONFIG`）
- 其余项（排除名单、目录名等）一般无需修改

## 与调度器的衔接（硬性）

- 阶段收尾：`advance` 推进状态（产物版本自动 +1）→ `check --stage` 校验 → 对话输出阶段执行报告
- ERROR ≥ 1 → **不得进入下一阶段 / 不得交付**；WARN → 允许继续但写入报告
- 校验器缺失或无法运行 → 降级为清单自查 + 按 `规范/异常设计.md` 记异常（见 跟新规范 规范清单）
- 版本防护：重构改写产物前先 `check` 读取该产物版本记录，禁止旧覆盖新（见 重构基础模块【差异与授权】）

## 自检（回归）

- `selftest`：内置 4 组用例（合规工作区 0 ERROR、问题提示词逐项报错、坏状态文件、init/advance 往返与回退拒绝），任何一项失败退出码 1——**修改校验器后必须先跑 selftest**
- 系统性回归（多场景、质量评价）见 `工具/回归测试.md`
