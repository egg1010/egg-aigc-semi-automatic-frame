# 联动模块（CROSS-MODULE COORDINATION）

**作用**：材质 / 光线 / 皮肤 / 色彩 四个模块**联合设计参数**，互相配合，禁止各模块独立选参。
**定位**：本模块不替代四个知识模块（材质/光线/皮肤/色彩），只定义它们之间的耦合规则与输出协议。

## 输入源｜图片分析（可选）

- 有参考图 → 运行 `通用模块/图片分析限制模块.md` → 产出【图片分析报告】，逐项承接：
  - **材质清单表**：逐条进参数设计表 —— 每个主材质至少一行（参数含 类别/表面状态/反射特性），并按 R2 标注需要写出的环境反射元素；禁止把整张图压缩成一句"金属+布料"
  - **站位分析表**（仅站位图）：进参数设计表的「空间/站位」行，落点为 基础格式的【空间布局】
- 风格（光线/色彩/影调）只由文本要求决定（剧本/用户指定/风格基线），禁止从图片提取，不随图片变化
- 没有图片 → 纯文本模式：跳过图片分析，全部参数依据文本要求 + 通用模块四库设计
  - ★ **详细度与图片模式一致**：从剧本提取主要承载物/材质（服装、武器、道具、建筑表面、载具…），逐条设计进参数设计表材质行，来源标 `文本:剧本描述`；禁止因无图就只给一句笼统材质描述

## 联动总则

1. 物理优先级：`光线 > 材质响应 > 皮肤表现 > 色彩氛围`
2. 下级参数不得违反上级的物理结果（调色是氛围偏移，不是第二套光照）
3. 参数成组选择：每确定一个参数，必须检查它触发或约束的其他模块参数并同步修改

## 联动规则

### R1 光线 → 皮肤

| 光线条件 | 皮肤联动 | 提示词写法 |
|---|---|---|
| 硬光（小光源、高对比） | 高光锐利，毛孔与瑕疵被放大 | 油光仅限 T 区/颧骨等局部 |
| 软光（大面积柔光） | 高光弥散，瑕疵柔化 | 皮肤细腻均匀、柔和高光 |
| 侧逆光/强侧光 | 透出次表面散射 | 耳廓、鼻翼边缘透光 |
| 冷色光 | 肤色偏青 | 肤色保持自然血色，不发青 |
| 顶光 | 眼窝/鼻下阴影加重 | 配合杜绝项：眼窝不发黑 |

### R2 光线 → 材质

| 光线条件 | 材质联动 | 提示词写法 |
|---|---|---|
| 高金属度材质 | 必须有可反射的环境 | 写出环境元素（窗、灯、天光），否则金属发黑 |
| 低粗糙度（光滑面） | 高光锐利 | 配点状/小面积光源 |
| 高粗糙度 | 高光弥散 | 配面光源/柔光 |
| 织物绒面 | 逆光/侧光才出绒毛光 | 轮廓光勾出织物边缘绒毛 |
| 清漆层（车漆/漆器） | 双层反射 | 面漆高光 + 底漆反射分层描述 |

### R3 色彩 → 光线

| 色彩意图 | 光线联动 | 提示词写法 |
|---|---|---|
| 暖调（怀旧/亲密） | 主光源约 3200K | 高光偏黄，阴影补冷形成冷暖对比 |
| 冷调（疏离/紧张） | 主光源 5600K+ | 高光偏蓝，暗部保留极少量暖 |
| 暗部冷+亮部暖 | 对应调色分区（Lift/Gain） | 光比分区与调色分区保持一致 |
| 有冲突时 | — | 以光源色温为物理依据，调色只做氛围偏移 |

### R4 色彩 → 皮肤

| 色彩意图 | 皮肤联动 | 提示词写法 |
|---|---|---|
| 全片低饱和/褪色 | 肤色单独保护 | 肤色饱和度保持自然 |
| 整体冷调 | 保留血色 | 嘴唇、指尖保留微暖血色，不发灰 |
| 强对比/暗调 | 阴影里的脸不许死黑 | 暗部肤色保留层次 |

### R5 材质 ↔ 皮肤

| 规则 | 说明 |
|---|---|
| 皮肤即材质 | 毛孔（微法线）+ 微粗糙 + 油脂层 + 次表面散射 成组出现 |
| 汗/血/妆 | 改变皮肤反射写法：汗湿=高光增强，哑光妆=高光减弱 |
| 服装接触区 | 领口/袖口仅换材质描述，肤色保持一致 |

## 双体系参数｜影视 × 游戏

参数设计表中，影视实拍体系与游戏渲染体系**并列出现**，双体系都要有代表参数，描述取更详细的一支。

### 影视实拍体系（丰富选项）

| 模块 | 可选参数 | 说明 |
|---|---|---|
| 光线 | 三点布光／伦勃朗光／分割光／蝴蝶光／轮廓光／practicals 实用光源／自然光动机／混合色温 | 决定阴影方向与情绪 |
| 光线 | 色温 3200K（钨丝灯）／4300K（日光混合）／5600K（日光）／烛光级低色温 | 暖怀旧 ↔ 冷客观 |
| 色彩 | LGG 分区调色／S 曲线／互补色（橙青）／胶片色彩：漂白 bleach bypass／褪色 fade／染印法 three-strip | 氛围层 |
| 色彩 | 胶片颗粒／暗角／柔光滤镜（Black Pro-Mist）／Bloom 光晕／镜头匹配 | 质感层 |
| 材质 | 微表面可见／真实磨损与氧化／织物纹理与绒面／木质包浆／金属拉丝 | 实拍材质真实感 |
| 皮肤 | 保留毛孔与血色／自然油脂高光／SSS 透光／真实瑕疵（雀斑、细纹） | 实拍皮肤基准 |

### 游戏渲染体系（丰富选项）

| 模块 | 可选参数 | 说明 |
|---|---|---|
| 光线 | 实时光影／屏幕空间反射 SSR／体积光 God Rays／全局光照 GI／光探针 | 引擎光效 |
| 色彩 | 色调映射 Tone Mapping（ACES/Filmic）／HDR Bloom／色差 chromatic aberration／色彩抖动／风格化分级 | 后期链 |
| 材质 | PBR（金属度/粗糙度双参数）／ClearCoat 清漆／Sheen 绒面／自发光 Emissive／法线强度／视差贴图 | 引擎材质参数 |
| 皮肤 | SSS 皮肤散射配置／毛孔法线强度／油脂层控制／数字双瞳一致性 | 数字皮肤方案 |

### 双体系合流规则

1. 参数设计表每行标注体系：`影视`／`游戏`／`通用`
2. 未明确要求：影视为主（物理可信），游戏参数仅取视觉增强项（Bloom／色调映射／颗粒等）
3. 用户明确要游戏风／CG 风：游戏体系可为主，但皮肤与光线仍受 R1/R4 约束
4. 两体系参数冲突 → 按联动总则物理优先级裁决；无法判定 → 按 `规范/异常设计.md` 写入

## 深挖选参协议（AI 自己裁决，禁止跳过对比）

每个模块执行一次"菜单 vs 词典深挖"对比，胜者进参数设计表：

1. 从画面要求提取关键词 → 查【知识库检索索引】→ 每个模块定位 1-3 个候选章节
2. 阅读候选章节 → 每个模块挑出 1-2 个"深挖候选"参数，与 菜单/基线参数 对比
3. AI 裁决：哪个参数对**当前风格**更好 → 胜者进参数设计表（来源标 `深挖:模块§章节号`）
4. 若菜单/基线参数更优 → 也必须记录一行对比结论（来源标 `对比:模块§X 未更优`），证明翻过词典
5. 拿不准时优先选描述更具体、与画面要求因果更直接的参数；两难 → 按 `规范/异常设计.md` 写入

## 写写实拍风格基线（无明确要求时的联合默认）

- 色彩：色温 4300-5600K，中高对比 S 曲线，低饱和偏胶片，暗部冷亮部微暖
- 光线：三点布光（主光+补光+轮廓光），软硬适中，有自然光动机
- 材质：微表面可见，反射符合环境，无塑料感
- 皮肤：保留毛孔与血色，高光柔和不过曝

## 自检清单（全部通过才能写提示词）

1. 每条触发的联动规则（R1-R5）在提示词里都有对应落点
2. 输出格式的对应槽位逐项可溯源到参数设计表（视频模块指 `视频模块/基础格式.txt` 的【影调】）
3. 无跨模块矛盾（例：写硬光却要求柔和高光）
4. 肤色保护（R4）在整体调色下仍成立
5. 每个模块都有至少一行 深挖/对比 记录，词典真的翻过
6. 无法判定的冲突 → 按 `规范/异常设计.md` 写入，不得自行二选一；问题过于严重 → 询问用户
7. 材质落点检查：图片模式 —— 材质清单每个主材质在 提示词【影调·材质】都有落点行；文本模式 —— 剧本主要承载物/材质逐条有落点行
8. 站位落点检查：有站位图时，站位分析表内容已写入【空间布局】，未丢失遮挡关系与朝向
