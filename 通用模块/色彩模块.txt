【一、基础颜色属性】

颜色（Color）：控制整体色彩表现；常见颜色模型包括 RGB、HSV、HSL、Lab、XYZ。
RGB 通道：红（Red）、绿（Green）、蓝（Blue），可分别控制各通道的亮度、对比度、曲线、黑位和白位。
色相（Hue）：决定颜色种类；色相偏移（Hue Shift）控制整体颜色沿色环移动；选择性色相（Selective Hue）只改变指定颜色范围。
饱和度（Saturation）：控制颜色鲜艳程度；自然饱和度（Vibrance）优先增强低饱和区域，通常比整体饱和度更柔和。
明度（Value / Lightness）：控制颜色本身的明暗；亮度（Brightness）控制整体视觉亮度。
色调（Tint）：给整体画面增加颜色倾向，也常用于绿—洋红方向的白平衡微调。

【二、曝光与明暗】

曝光（Exposure）：控制整体曝光，常以 EV / Stop 表示；增加 1 档约等于亮度翻倍。
曝光补偿（Exposure Compensation）：在当前曝光基础上进行整体偏移。
亮度（Brightness）：直接调整整体亮暗；对比度（Contrast）：控制亮部和暗部差异。
黑位（Black Level）：控制最暗区域；白位（White Level）：控制最亮区域。
阴影（Shadows）：控制暗部；中间调（Midtones）：控制主要中间亮度区域；高光（Highlights）：控制亮部。
黑色色阶（Blacks）：主要影响接近纯黑区域；白色色阶（Whites）：主要影响接近纯白区域。
动态范围（Dynamic Range）：决定画面可保留的最暗到最亮范围；高动态范围可容纳更多明暗细节。

【三、Lift / Gamma / Gain / Offset】

提升（Lift）：主要控制暗部亮度和暗部颜色。
伽马（Gamma）：主要控制中间调亮度和颜色。
增益（Gain）：主要控制高光和亮部。
偏移（Offset）：整体移动图像信号，同时影响暗部、中间调和高光。
Lift / Gamma / Gain 是影视一级调色最常见的三段控制；Offset 常用于整体曝光和综合色偏修正。

【四、色温与白平衡】

色温（Temperature）：控制冷暖方向，通常以 Kelvin 表示；低色温偏黄橙，高色温偏蓝。
色调偏移（Tint）：主要用于绿色与洋红色方向修正。
白平衡（White Balance）：通过色温与 Tint 共同校正中性色。
白点（White Point）：决定系统认定的白色位置；常见白点包括 D65、D60。
自动白平衡（Auto White Balance）：根据画面自动判断中性区域；手动白平衡（Manual White Balance）：人工指定色温和 Tint。

【五、颜色轮】

阴影色轮（Shadow Wheel）：控制暗部色偏；中间调色轮（Midtone Wheel）：控制中间区域颜色；高光色轮（Highlight Wheel）：控制亮部颜色。
Lift Wheel、Gamma Wheel、Gain Wheel：分别对应暗部、中间调、高光。
Offset Wheel：调整整幅画面的综合色相偏移。
影视中常使用冷阴影 + 暖高光、暖阴影 + 冷高光等方式建立综合色彩关系。

【六、Log 色轮】

Log Shadows：控制较窄范围的暗部；Log Midtones：控制中间区域；Log Highlights：控制较窄范围高光。
Low Range：控制阴影作用范围；High Range：控制高光作用范围。
Log 调整相比普通 Lift / Gamma / Gain，对亮度区域的选择更精确。

【七、曲线】

主曲线（Master Curve）：整体控制亮度和对比度。
RGB 曲线（Red / Green / Blue Curves）：分别控制红、绿、蓝通道。
S 曲线：压低暗部并提升亮部，提高对比；反 S 曲线：降低对比。
黑场曲线：控制暗部层次；高光 Roll-off：控制高亮区域进入白色前的柔和过渡。
Toe：控制暗部曲线形状；Shoulder：控制高光曲线形状。

【八、Hue 曲线】

Hue vs Hue：根据原始色相修改目标色相，例如把绿色推向黄色。
Hue vs Saturation：根据色相改变饱和度，例如降低绿色饱和。
Hue vs Luminance：根据色相改变亮度，例如压暗蓝色天空。
Luminance vs Saturation：根据亮度控制饱和度，例如降低高光饱和度。
Saturation vs Saturation：根据原始饱和度重新映射饱和程度。
Saturation vs Luminance：根据饱和度改变亮度。

【九、选择性色彩】

选择性色彩（Selective Color）：单独调整红、黄、绿、青、蓝、洋红、白、中性、黑等颜色范围。
每个颜色范围可调整：青（Cyan）、洋红（Magenta）、黄（Yellow）、黑（Black）。
常用于肤色、天空、植物、服装、霓虹灯等局部精细控制。

【十、HSL / HSV】

Hue：色相；Saturation：饱和度；Lightness / Value：明度。
HSL Key：利用色相、饱和度和明度选择目标颜色。
Hue Range：色相范围；Saturation Range：饱和范围；Luminance Range：亮度范围。
Softness：控制选区边缘柔和程度；Denoise：减少选区噪声；Blur：平滑遮罩。

【十一、颜色键与二级调色】

Qualifier / Keyer：选择某种颜色区域。
HSL Key：基于色相、饱和度、亮度选择；RGB Key：基于 RGB 范围选择。
Key Gain：控制选区强度；Key Output：控制最终遮罩输出。
Matte Black / White：查看遮罩；Clean Black / Clean White：清理遮罩；Blur Radius：柔化边缘。
二级调色常用于肤色、天空、服装、墙面、植物、灯光等局部区域。

【十二、Power Window / Mask】

圆形遮罩、矩形遮罩、多边形遮罩、曲线遮罩、渐变遮罩。
位置（Position）、尺寸（Size）、旋转（Rotation）、羽化（Feather）、柔边（Softness）、透明度（Opacity）。
Inside / Outside：控制遮罩内部或外部；Invert：反转遮罩。
Tracking：跟踪人物或物体；Perspective Tracking：考虑透视变化。

【十三、肤色控制】

肤色色相（Skin Hue）：控制肤色偏红、偏黄、偏橄榄等倾向。
肤色饱和度（Skin Saturation）：控制肤色鲜艳程度；肤色亮度（Skin Luminance）：控制皮肤明暗。
Skin Tone Line：用于判断肤色色相是否偏离自然范围。
Redness：控制脸部泛红；Warmth：控制肤色暖感；Skin Contrast：控制皮肤层次。
肤色保护（Skin Tone Protection）：进行整体风格调整时减少对人物肤色的影响。

【十四、色域】

色域（Color Gamut）：颜色系统能够表示的范围。
常见色域：sRGB、Rec.709、DCI-P3、Display P3、Rec.2020、ACES AP0、ACEScg / AP1。
Gamut Mapping：把超出目标色域的颜色映射回可显示范围。
Gamut Compression：压缩高饱和超色域颜色，减少断层和颜色剪切。
Out of Gamut：超出目标色域的颜色。

【十五、传递函数与 Gamma】

Gamma：控制亮度编码与显示响应。
常见 Gamma：2.2、2.4、2.6。
sRGB Transfer Function：标准显示与网页常用。
Rec.709：传统 HDTV 视频常用。
PQ（ST 2084）：HDR10 等 HDR 系统常用。
HLG：广播 HDR 常用。
Log：摄影机记录高动态范围常用的对数曲线。

【十六、Log 曲线】

常见摄影机 Log：ARRI LogC、Sony S-Log、Canon Log、RED Log3G10、Panasonic V-Log、Blackmagic Film。
Log 曲线特点：低对比、低饱和、保留更大动态范围。
需要通过 Color Space Transform、LUT 或色彩管理转换到最终显示空间。

【十七、ACES 色彩管理】

ACES：影视制作中广泛使用的统一色彩管理体系。
ACES2065-1：ACES 主交换空间；ACEScg：CG 渲染常用线性色彩空间。
IDT（Input Device Transform）：将摄影机输入转换到 ACES。
LMT（Look Modification Transform）：添加创作风格。
RRT / Output Transform：把场景颜色转换到显示设备。
ODT：传统 ACES 工作流中的输出设备变换概念。
ACEScg 常用于 Maya、Arnold、Houdini、Nuke、Blender、VFX 与高端 CG 流程。

【十八、OCIO 色彩管理】

OpenColorIO（OCIO）：影视与游戏 CG 中常用的色彩管理系统。
Input Color Space：输入色彩空间；Working Space：工作空间；Display：显示设备；View：查看变换；Look：风格变换。
常用于 Nuke、Maya、Arnold、Houdini、Blender、Substance、Unreal 等软件之间保持颜色一致。

【十九、线性工作流】

Linear Workflow：灯光和渲染计算通常在线性空间进行。
Linear RGB：用于光照、混合、合成等物理计算。
Texture Color Space：颜色纹理通常需要正确解码；数据纹理如 Roughness、Normal、Metallic 通常不能按颜色 Gamma 处理。
错误的色彩空间设置会导致材质、灯光、合成结果偏亮、偏暗或对比异常。

【二十、输入色彩空间】

Input Color Space：告诉软件素材原本属于哪个空间。
常见输入：sRGB、Rec.709、LogC、S-Log、ACEScg、Linear、Raw。
错误指定输入空间会导致色彩和曝光完全失真。

【二十一、输出色彩空间】

Output Color Space：决定最终输出目标。
常见输出：sRGB、Rec.709 Gamma 2.4、DCI-P3、Display P3、Rec.2020、HDR10 PQ、HLG。
影视院线、流媒体、电视、网页、游戏主机、手机等可能使用不同目标空间。

【二十二、色彩空间转换】

Color Space Transform（CST）：在不同色彩空间之间转换。
Input Color Space：输入色域；Input Gamma：输入传递函数。
Output Color Space：目标色域；Output Gamma：目标传递函数。
Tone Mapping：处理动态范围差异；Gamut Mapping：处理色域差异。

【二十三、LUT】

LUT（Look-Up Table）：通过查找表转换颜色。
1D LUT：主要控制单通道亮度曲线；3D LUT：可以同时改变亮度、色相、饱和度。
Technical LUT：技术转换，例如 Log → Rec.709；Creative LUT：建立视觉风格。
LUT Intensity / Mix：控制 LUT 强度；Interpolation：控制 LUT 插值方式。
LUT 不应代替完整色彩管理。

【二十四、Tone Mapping】

色调映射（Tone Mapping）：把高动态范围场景压缩到显示设备能够表现的范围。
Exposure：整体曝光；Toe：暗部压缩；Shoulder：高光压缩；White Point：白点；Black Point：黑点。
Highlight Roll-off：控制高光进入白色的过渡；Shadow Roll-off：控制暗部进入黑色的过渡。
Filmic Tone Mapping：模拟电影式柔和高光和对比响应。

【二十五、Filmic 参数】

Toe Strength：控制暗部压缩；Toe Length：控制暗部影响范围。
Shoulder Strength：控制高光压缩；Shoulder Length：控制高光影响范围。
Linear Strength：控制中间线性区域；Linear Angle：控制中间曲线坡度。
White Clip：控制最亮区域剪切。
常用于游戏引擎、实时渲染和电影感画面。

【二十六、HDR】

HDR：高动态范围显示。
Peak Brightness：峰值亮度；常使用 nits / cd/m²。
Paper White：HDR 中参考白亮度；Black Level：显示设备黑位。
MaxCLL：内容最大亮度；MaxFALL：平均画面最大亮度。
HDR10：常使用 Rec.2020 容器 + PQ；HLG：广播 HDR；Dolby Vision：支持动态元数据。
游戏 HDR 还需考虑显示器校准和 UI 亮度。

【二十七、SDR】

SDR：标准动态范围。
常见目标：Rec.709 / sRGB。
Reference White：参考白；Black Level：黑位；Gamma 2.2 / 2.4：显示环境相关。
影视 SDR 母版通常比普通电脑显示更强调标准观看环境。

【二十八、颜色压缩与剪切】

Highlight Clipping：高光超出范围直接变成纯白。
Shadow Clipping：暗部超出范围变成纯黑。
Channel Clipping：单独某个 RGB 通道溢出，会产生异常色偏。
Soft Clip：柔和压缩极端高光或暗部。
Gamut Clip：超出色域后直接裁切；Gamut Compression：更柔和地压缩回来。

【二十九、色彩分离】

Color Separation：增加不同颜色之间的区分。
Hue Separation：增加色相差异；Luminance Separation：增加亮度差异；Saturation Separation：增加饱和度差异。
常用于让角色和背景产生更清晰的颜色层次。

【三十、冷暖关系】

Warm / Cool Balance：控制综合色彩冷暖关系。
暖色：红、橙、黄；冷色：蓝、青、部分绿色。
常见组合：暖主光 + 冷环境、冷阴影 + 暖高光、暖人物 + 冷背景、冷人物 + 暖背景。
Color Contrast：通过互补色或冷暖对比增强视觉重点。

【三十一、互补色】

互补色常见组合：红—青、绿—洋红、蓝—黄。
Complementary Balance：控制互补关系强度。
影视和游戏经常使用橙蓝关系建立主体和环境分离，但应根据场景而非机械套用。

【三十二、综合色彩和谐】

单色（Monochromatic）：围绕一个主色变化。
邻近色（Analogous）：使用色环上相邻颜色。
互补色（Complementary）：使用相对颜色。
分裂互补（Split Complementary）：主色配两个相邻互补色。
三角色（Triadic）：三个等距色相。
综合色盘（Color Palette）：控制整个项目的主色、辅色、强调色。

【三十三、综合色偏】

Color Cast：画面整体偏向某种颜色。
Warm Cast：偏黄橙；Cool Cast：偏蓝青；Green Cast：偏绿；Magenta Cast：偏洋红。
可通过 White Balance、Offset、RGB Curves、Color Wheels 等修正或有意创造。

【三十四、综合色调密度】

Color Density：颜色的浓厚程度，不完全等于饱和度。
增加密度：颜色更厚重、更深；降低密度：颜色更轻、更薄。
影视胶片风格中常通过密度而不是单纯提高 Saturation 获得浓郁色彩。

【三十五、综合色彩纯度】

Color Purity：颜色接近纯色的程度。
降低纯度：加入灰或互补色，颜色更自然；提高纯度：颜色更直接鲜艳。
环境、皮肤和服装通常需要不同程度的纯度控制。

【三十六、胶片色彩】

Film Emulation：模拟胶片的色彩响应。
Film Contrast：胶片式对比；Film Saturation：胶片式饱和；Film Density：胶片密度。
Highlight Compression：胶片高光柔化；Shadow Density：暗部厚度。
Color Crosstalk：模拟 RGB 层之间的综合色彩影响。
Film Print Emulation：模拟电影拷贝正片的综合色彩和对比响应。

【三十七、色彩串扰】

Color Crosstalk：一个 RGB 通道影响其他通道。
适当串扰可产生更自然的高光颜色过渡和胶片感。
完全独立的 RGB 通道在极端颜色中可能显得数字感更强。

【三十八、漂白效果】

Bleach Bypass：模拟银漂保留。
典型效果：饱和度降低、对比度增强、黑位加深、颗粒感增强。
Bleach Strength：控制效果强度。

【三十九、褪色】

Fade：降低黑白反差并减少综合色彩密度。
Fade Amount：控制褪色程度；Lifted Blacks：抬高黑位；Reduced Whites：降低高光。
可用于旧电影、回忆、年代感或风格化游戏画面。

【四十、颜色分级】

Primary Grade：一级调色，负责曝光、白平衡、整体对比、综合色彩。
Secondary Grade：二级调色，负责局部区域和特定颜色。
Look Development：建立视觉风格。
Shot Matching：镜头匹配；Scene Matching：场景匹配；Sequence Matching：整段统一。

【四十一、镜头匹配】

Exposure Match：匹配曝光；White Balance Match：匹配白平衡。
Contrast Match：匹配对比；Saturation Match：匹配饱和度。
Skin Tone Match：匹配肤色；Background Match：匹配环境综合色彩。
影视剪辑中不同机位、摄影机和拍摄时间都需要综合色彩一致性。

【四十二、游戏后期色彩】

游戏实时后期常见参数：Exposure、Auto Exposure、White Balance、Temperature、Tint、Contrast、Saturation、Gamma、Gain、Offset、Color Grading LUT、Tone Mapping、Bloom、Vignette、Film Grain、Chromatic Aberration。
还常分为 Global、Shadows、Midtones、Highlights 四套综合色彩控制。

【四十三、游戏阴影色彩】

Shadow Color：暗部综合色调；Shadow Saturation：暗部饱和度；Shadow Contrast：暗部对比度。
Shadow Tint：给阴影增加综合色彩倾向；Shadow Threshold：定义暗部影响范围。

【四十四、游戏中间调色彩】

Midtone Color：控制中间调综合色偏；Midtone Saturation：控制中间调饱和度。
Midtone Contrast：控制中间区域层次；Midtone Gamma：控制中间亮度。

【四十五、游戏高光色彩】

Highlight Color：控制亮部综合色调；Highlight Saturation：控制亮部饱和度。
Highlight Gain：控制亮部强度；Highlight Threshold：决定高光范围。
Highlight Desaturation：降低极亮区域饱和度，减少数字感和颜色爆炸。

【四十六、自动曝光】

Auto Exposure：根据画面亮度自动改变曝光。
Min EV：最低曝光；Max EV：最高曝光；Exposure Compensation：整体偏移。
Speed Up：从暗到亮的适应速度；Speed Down：从亮到暗的适应速度。
Metering Mode：平均测光、直方图测光、局部测光等。
游戏中自动曝光对室内外切换、洞穴、夜景等非常重要。

【四十七、局部曝光】

Local Exposure：根据画面局部亮度分别调整曝光。
Highlight Contrast：控制亮区局部对比；Shadow Contrast：控制暗区局部对比。
Detail Strength：保留局部细节；Blurred Luminance：控制局部亮度分析尺度。
常用于 HDR 与游戏实时环境。

【四十八、Bloom 色彩相关】

Bloom Intensity：辉光强度；Bloom Threshold：开始产生 Bloom 的亮度阈值。
Bloom Tint：辉光颜色；Bloom Radius：辉光范围。
高饱和 Bloom 会显著改变综合色彩，因此属于重要的最终色彩感知参数。

【四十九、色差】

Chromatic Aberration：模拟镜头不同波长光线聚焦位置差异。
Intensity：强度；Start Offset：开始出现的位置；Color Fringe：边缘颜色。
通常用于镜头感或风格化，过强会明显破坏综合色彩清晰度。

【五十、暗角】

Vignette：降低画面边缘亮度。
Intensity：暗角强度；Color：暗角颜色；Roundness：形状；Feather：柔边。
除了引导视线，也会改变画面的整体综合色彩重量。

【五十一、胶片颗粒】

Film Grain：增加颗粒。
Intensity：强度；Size：颗粒尺寸；Response：颗粒随亮度的变化。
Colored Grain：彩色颗粒；Monochrome Grain：单色颗粒。
颗粒会影响综合色彩纯净度、暗部质感和画面统一性。

【五十二、色彩抖动】

Dithering：在有限位深下加入微小噪声，减少综合色彩断层。
Dither Strength：强度；Temporal Dither：时间抖动；Spatial Dither：空间抖动。
游戏天空、雾、暗部渐变中尤其重要。

【五十三、综合色彩断层】

Banding：平滑渐变出现明显色阶。
常见原因：位深不足、压缩过强、后期曲线过激、暗部处理过重。
解决方式：提高位深、Dithering、减少极端曲线、使用更合理色彩空间。

【五十四、位深】

Bit Depth：每个通道能够记录的颜色精度。
8-bit：常规网页和大量游戏输出；10-bit：HDR 和高质量视频常用；12-bit / 16-bit：影视制作与高质量图像常用；16-bit Half Float / 32-bit Float：VFX 与 CG 合成常用。
位深越高，渐变越平滑，后期调整空间越大。

【五十五、浮点颜色】

Half Float：常见 16-bit 浮点图像格式；Float：32-bit 浮点。
允许保存超过 0～1 的高动态范围值。
EXR 是影视 CG、灯光和合成中非常常见的高动态范围格式。

【五十六、显示参考】

Reference Monitor：标准参考监视器。
Display Calibration：显示器校准；White Point：白点；Peak Luminance：峰值亮度；Black Level：黑位。
Ambient Light：观看环境光也会影响综合色彩判断。
影视调色必须尽量保持固定和标准化的观看环境。

【五十七、综合色彩管理核心】

输入色彩空间、工作色彩空间、显示色彩空间、输出色彩空间、Gamma、Log、Tone Mapping、Gamut Mapping、White Point、Transfer Function、LUT、OCIO、ACES。
这些参数决定颜色是否能够在摄影机、CG、合成、游戏引擎和最终显示设备之间保持一致。

【五十八、影视常用核心色彩参数】
