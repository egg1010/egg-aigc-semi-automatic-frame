# 图片分析限制模块（IMAGE ANALYSIS CONSTRAINTS）

**作用**：约束参考图分析的唯一用途——提取材质与站位。风格永远来自文本，不来自图片。
**详细度要求**：分析输出必须是「可逐条落进参数设计表」的结构化明细，禁止只给单词级结论（如只写"金属、布料"）。

## 硬性限制

- 图片分析唯一用途：提取材质（站位图另加站位）
- 禁止从图片分析 色彩、光线、画面风格 —— 风格由文本要求决定，不随图片变化
- 图片中观察到的光影/色彩印象 → 仅可用于反推材质的反射特性（如"高光锐利 → 低粗糙度"），不得写进 光线/色彩 参数

## 分析顺序

1. 优先分析站位图（没有则不分析）
2. 上传的图片 → 分析所有材质
3. 同一张图兼具站位 + 材质 → 两张表都出

## 输出｜图片分析报告（结构化，必写）

### A. 材质清单表（每张图逐项列出）

| 材质名 | 承载物/出现位置 | 类别 | 表面状态 | 反射特性 | 画面重要度 | 深挖锚点 |
|---|---|---|---|---|---|---|
| 例：做旧黄铜扣件 | 主角腰带上第2-3颗扣 | 金属-黄铜 | 氧化+边缘磨亮 | 高光中等偏锐；可反射周围织物色 | 主材质 | 材质§34金属 §28磨损 |

填写要求（逐条硬性）：

1. **类别**写到子类：金属/织物/皮革/木质/玻璃/水/冰/漆面/塑料/皮肤/石材…（黄铜≠金属，呢料≠织物）
2. **表面状态**逐项排查：新旧 / 磨损 / 污渍 / 湿润 / 锈蚀 / 氧化 / 绒面 / 清漆层 / 指纹油光，命中才写、写了必具体
3. **反射特性**：高光软硬 + 粗糙度档位（光滑/中等/粗糙）+ 可被反射的环境内容物
4. **画面重要度**：主材质（人物穿戴/手持/贴脸道具/画面占比大）必进参数设计表；次要材质（背景小物件）选进
5. **深挖锚点**：预判材质模块§章节号，供联动模块【深挖选参协议】直接检索

### B. 站位分析表（仅站位图）

| 项目 | 分析内容 |
|---|---|
| 机位/视角 | 俯仰角、机位高度、景别倾向 |
| 人物站位 | 每人：位置（画面九宫格）+ 朝向 + 与镜头距离 + 相互高度差 |
| 遮挡关系 | 谁挡谁、遮挡比例、视线是否被切断 |
| 道具位置 | 关键道具在哪、谁手持 |
| 景深层次 | 前景/中景/背景各有什么 |
| 画面重心 | 视觉焦点落点、可用负空间 |

**2D 俯视站位图（简笔/矢量示意图）专用翻译流程**——图上只有符号没有画面，禁止直接套照片分析法，按五步翻译：

1. **图例识别**：先声明符号含义（圆点/小人=人物、箭头=朝向、方框=家具道具、三角=机位）——各图制图习惯不同，禁止猜；图上没画的符号（如机位）标注「图未提供」
2. **硬信息读取**（图上直接有的，用空间参照物定位，不用裸左右）：
   - 位置：每人挂在参照物上（门旁/长桌短边/窗前/沙发左侧）——参照物是家具与出入口，不是"图的左边"
   - 朝向：箭头指向 → 面向场景内实体（面向门口/背对窗/两人相对）
   - 距离档位：用家具尺寸换算（贴身<0.5m／一步1m／对话1.5-2m／隔桌3m／房间两端5m+）
   - 道具位置与手持归属、出入口位置（后续衔接用）
   - **场景罗盘**（方位基准）：图面默认上=北（制图惯例）；若图上标注罗盘/指北针 → 以标注为准并声明——**若用户声明真实方位**（如「图的上方是东」）→ 全部方位描述换算到真实东南西北后输出；未声明 → 以图面方位为准输出并标注「图面方位，上=北」。此后所有位置/朝向/门窗/机位描述统一用同一罗盘基准，本场各镜头不得混用两套基准
3. **机位推导**（图未画机位时执行；画了 → 以图为准并声明）：找主要人物连线 = 关系轴 → 机位置于轴线**一侧**（180°规则），本场全部镜头同侧不跨轴
4. **画面特征推导**（机位定了才能算，逐项换算）：
   - 画面左右换算（最易错，强制显式换算）：机位从图的 X 侧看向场景 → 图上 Y 侧 = 画面**左/右**——禁止把图上位置直接当画面位置
   - 九宫格落位：机位 + 各人图上位置 → 画面九宫格
   - 遮挡：机位视线 × 前景人物/家具高度 → 谁挡谁、挡多少（俯视图本身无遮挡信息）
   - 景深层次：从机位往深处排 前景/中景/背景
5. **产出站位分析表**（上表格式不变）→ 联动模块「空间/站位」行 → 基础格式【空间布局】

2D 站位图为纯内容图（简笔/矢量/示意）——风格零继承，仅提取空间内容，依据 联动模块【风格锚定总则】规则4。

**3D 立体站位图（透视渲染/轴测示意图）分析流程**——图有立体深度但渲染视角属性不明，先判定再分析，禁止默认：

1. **视图类型判定**：透视渲染（有灭点、近大远小）／轴测·等距（无灭点、物体不随深度缩放、多角度同尺寸）
2. **机位属性判定**（关键分叉，必须显式判定）：
   - 用户明确「按此视角拍」→ 渲染视角 = 拍摄机位 → 画面特征（九宫格/遮挡/景深）**直接读取**，同照片分析法，并在站位分析表声明「机位=渲染视角」
   - 未明确 → 3D 图仅作**布局参考**：只读取空间关系（各人位置挂参照物/朝向/相互距离/道具归属），机位/九宫格/遮挡/景深仍按 2D 流程第3-4步轴线推导
3. **透视渲染专有**：距离用透视缩放换算——以人物身高/家具实际尺寸为标尺（近处1.7m人占画面高1/2 → 推算相机约2m内）；遮挡与景深按渲染画面直读
4. **轴测图专有**：无灭点禁止直接当画面用——前后层次与遮挡可读，但九宫格/景深必须机位推导；距离按图例比例尺或家具尺寸换算（等距无透视缩放，勿用近大远小估距）
5. **多视图 3D**（正面/侧面/俯视多张同给）：交叉验证还原真实空间关系 → 再选定机位推导——信息最全，优先采用并在表中声明；各视图的罗盘方位须互相一致（同一主门在俯视图=南墙、在透视图=画面深处的右墙 → 统一罗盘后才能合并，矛盾 → 记录冲突）
6. **3D 图罗盘**：与 2D 同规则——用户声明真实方位 → 换算后输出；未声明 → 以视图默认朝向为准并标注「视图方位」。透视渲染/轴测非正俯视，方位描述以「画面深处=场景X向」方式换算声明，禁止把画面方向直接当罗盘方向
7. 3D 站位图同样为内容图——CG 渲染质感/模型贴图风格零继承，仅提取空间内容，依据 联动模块【风格锚定总则】规则4。

**站位图 × 场景图 交叉验证（2D/3D 通用，两张图都有时强制执行）**——站位图管空间关系、场景图管环境视觉，合并前必须逐项对齐，禁止各读各的：

1. **职权划分**：站位图 = 空间关系权威（谁在哪/朝哪/隔多远）；场景图 = 环境结构权威（房间形状/门窗位置/家具实貌/材质视觉）
2. **参照物存在性核对**：站位图每人挂的参照物（门/窗/长桌/沙发/柱）必须在场景图中找到实物——找不到 → 记录冲突，不得凭空保留
3. **布局一致性核对**：出入口位置/家具排布/房间形状 两图对照——矛盾 → 记录冲突
4. **尺度核对**：站位图距离档位 × 场景图实际空间量级匹配（站位图隔桌3m，场景图桌子须容得下3m宽距；房间两端5m+ 则场景图须是大厅而非斗室）
5. **朝向锚定转移**：站位图「面向门口/背对窗」的锚定物，以场景图实际位置为准重新落位（站位图上画的门在北墙、场景图里门在东墙 → 按场景图修正朝向描述）
6. **罗盘对齐**：两图统一到同一罗盘基准——站位图的「门在南墙」与场景图的门实际所在墙须方位一致；不一致 → 按场景图修正站位图方位描述并记入修正清单
7. **冲突裁决**：环境结构冲突 → 以场景图为准并声明「按场景图修正」；空间关系冲突（站位图自身矛盾）→ 以站位图重读为准；无法裁决 → 按规范 异常设计.md 处理
8. **产出**：验证通过 → 站位分析表各参照物标注「已与场景图对齐」；有修正 → 表末附「修正清单」（改了什么/依据哪张图）

## 输入分支

- 有图：图片分析报告仅供 联动模块/重构基础模块 的 材质参数 + 空间站位 设计使用
- 无图：纯文本模式 —— 材质/光线/皮肤/色彩 全部依据 文本要求 + 通用模块四库 设计
  - ★ **详细度要求不变**：从剧本提取主要承载物/材质（服装、武器、道具、建筑表面、载具…）逐条设计，粒度与图片模式一致，来源标注 `文本:剧本描述`；禁止因无图就只给一句笼统材质描述
