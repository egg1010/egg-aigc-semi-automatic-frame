# 图片提示词模块调度器（IMAGE PROMPT DISPATCHER）

## 步骤1｜查找输入

- 需要的输入：剧本与资产表信息（来自 文本模块 的理解与拆分结果），在工作区目录查找
- 如果没有 → 异常 → 跳到 收尾，之后终止运行
- ★ 架构文件缺失处理：`通用模块/色彩模块.txt`、`通用模块/光线模块.txt`、`通用模块/材质模块.txt`、`通用模块/皮肤模块.txt`、`通用模块/联动模块.md`、`图片提示词模块/人物图片资产格式.txt`、`视频模块/重构基础模块.md`（重构分支）预设路径不存在 → **先尝试寻找**（工作区范围内搜索同名文件）→ 确实找不到才异常 → 跳到 收尾：按 `规范/异常设计.md` 写入 `异常/日期异常.md` → 直接终止运行（不编造路径、不用默认顶替、不跳过继续）
- ★ 启动必读：运行 根目录 `跟新规范.md`（强制重新记忆规范；寻找与异常规则见该文件）
- 如果 `资产图提示词/人物场景提示词表.txt` 已存在且提示词后有「重构」标记
  → 不做全量生成，执行 `视频模块/重构基础模块.md` → 完成后跳到 收尾

## 步骤2｜生成资产图提示词

1. 在工作区创建 资产图提示词文件夹（已存在则不创建）
2. 创建 `资产图提示词/人物场景提示词表.txt`
   - 人物写在上面，场景在下面，可直接复制
3. 阅读 `规范/项目规范.txt`
   - 如果没有明确要求风格 → 默认「写实 实拍风格 电影感」
4. 依次阅读通用模块（必须按此顺序，与视频模块一致）
   1. `通用模块/色彩模块.txt`
   2. `通用模块/光线模块.txt`
   3. `通用模块/材质模块.txt`
   4. `通用模块/皮肤模块.txt`
5. 运行 `通用模块/联动模块.md` → 按【联动规则】联合设计参数
   - 材质/光线/皮肤/色彩 互相配合，禁止各模块独立选参
   - 先输出「参数设计表」中间产物 → 通过【自检清单】后再写提示词
6. **分析道具**：读取 资产表 最下面的 道具区 → 为每个需要的道具生成 资产图提示词
   - 道具提示词重点走 材质模块（表面质感、磨损、新旧程度），同样经过 联动流程
7. 人物提示词 → 必须遵守 `图片提示词模块/人物图片资产格式.txt` 模板（头肩四宫格 + 服装三视图 + 负面提示词）
8. 比例：如果没有明确说明 → 不写（不要默认值）
9. **严格遵循通用模块**：所有提示词的 风格/材质/光线/皮肤/色彩 参数必须取自 通用模块四库 + 联动模块（以「参数设计表」为准），禁止自由发挥或编造参数
10. 风格：如果没有明确说明 → 默认「写实 实拍风格 电影感」（以 规范/项目规范.txt 为准）
11. ★ 写实风格光线硬性要求：风格含 写实/实拍/电影感 → 光线描述必须写完整物理链（主光类型+方向+高度+软硬／色温K值／Key:Fill 光比／阴影／环境反射／分离手段），依据 联动模块【写实光线硬性要求】；光线/材质/皮肤/色彩 描述一律按【扩写成句协议】成句（含动词+场景具体对象，禁止标签串）；禁止「电影感光线」「柔和光线」等风格关键词单独代替布光，自检清单第9/10条不过 → 不得输出

## 输出格式（按全选项表的 输出格式 选项交付）

- **文本文件（默认）** → `资产图提示词/人物场景提示词表.txt`
- **Excel** → `资产图提示词/人物场景提示词表.xlsx`（人物/场景/道具 分区成表）
- **Markdown** → `资产图提示词/人物场景提示词表.md`
- **Word** → `资产图提示词/人物场景提示词表.docx`
- Excel/Word 需要脚本生成 → 脚本统一放 项目文件夹下 `工具/` 并复用（见 规范/项目规范.txt 第1条）

表内结构（四种格式同构）：

```text
人物
    xxx人物
        提示词（一行不要太长或太短，合理换行）
场景
    xxx场景
        提示词（一行不要太长或太短，合理换行）
道具
    xxx道具
        提示词（一行不要太长或太短，合理换行）
```

## 收尾

1. 无异常 → 不写任何文件，正常结束
2. 有异常 → 按 `规范/异常设计.md` 写入 `异常/日期异常.md`
