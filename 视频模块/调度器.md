# 视频模块调度器（VIDEO MODULE DISPATCHER）

**作用域**：仅限视频模块操作

## 步骤1｜初始化

1. 分段时长
   - 如果没有明确要求每一集的每一段是多少秒 → 默认每一段是 30秒
2. 记忆规范 ★ 启动必读
   - 运行 根目录 `跟新规范.md`（强制重新记忆 `规范/项目规范.txt`；附带记忆 `规范/多集要求.txt`，寻找与异常规则见该文件）
   - ★ 重点：记忆参数和规范，做出选择
3. 文件规范
   - 工作目录下有对应的剧集文件夹（可能是 xxx戏文件夹，也可能是数字命名）
   - 里面有 资产图 和 剧情
   - 剧情来源：文本拆分模块输出的分段文件（数字文件夹内的 x-a），按 集 进入
   - 资产图位置：单集文件夹内的 `资产图` 文件夹（文本拆分模块每集自动创建）
   - 最后在对应剧集文件夹内创建 提示词文件
   - 如果没有找到 剧集文件夹 → 异常 → 跳到 收尾，之后终止运行
4. ★ 架构文件缺失处理：`通用模块/色彩模块.txt`、`通用模块/光线模块.txt`、`通用模块/材质模块.txt`、`通用模块/皮肤模块.txt`、`通用模块/联动模块.md`、`通用模块/图片分析限制模块.md`（图片模式）、`视频模块/基础格式.txt`、`视频模块/重构基础模块.md`（重构模式）预设路径不存在 → **先尝试寻找**（工作区范围内搜索同名文件）→ 确实找不到才异常 → 跳到 收尾：按 `规范/异常设计.md` 写入 `异常/日期异常.md` → 直接终止运行（不编造路径、不用默认顶替、不跳过继续）

## 步骤2｜进入单集文件夹（可能是 xxx戏文件夹，也可能是数字命名）

判断模式（以单集文件夹内 `资产图` 文件夹的状态为判断依据）：

- 如果单集文件夹已有提示词文件且含「重构」标记 → 重构模式：执行 `视频模块/重构基础模块.md`，完成后跳到 步骤4 收尾
- 如果没有 `资产图` 文件夹，或 `资产图` 文件夹为空 → 文本模式
- 如果 `资产图` 文件夹内有图片 → 图片模式
  - 如果没有输入图片分析限制 → auto模式（由图片分析限制模块自动判定限制）

## 步骤3｜运行

按 步骤2 判定的模式执行。

- 画幅/比例：如果没有明确说明 → 不写（两种模式一致）
- ★ 详细度总要求（两种模式一致）：材质逐条设计、影调逐槽写满；无图模式详细度不得低于图片模式

**图片模式**

1. 确认风格（没有明确要求 → 默认「写实 实拍风格 电影感」）
2. `通用模块/图片分析限制模块.md` → 输出【图片分析报告】（材质清单表 + 站位分析表）→ 需要记忆，完整传入 联动模块
3. `通用模块/色彩模块.txt`
4. `通用模块/光线模块.txt`
5. `通用模块/材质模块.txt`
6. `通用模块/皮肤模块.txt`
7. `通用模块/联动模块.md` → 按【联动规则】联合设计参数（互相配合，禁止独立选参；图片分析报告逐项落进「参数设计表」：每个主材质至少一行 + 站位行；通过【自检清单】）
8. 最后 → 遵守 `视频模块/基础格式.txt` 输出提示词文件，位置是单集文件夹

**文本模式**

1. 确认风格（没有明确要求 → 默认「写实 实拍风格 电影感」）
2. `通用模块/色彩模块.txt`
3. `通用模块/光线模块.txt`
4. `通用模块/材质模块.txt`
5. `通用模块/皮肤模块.txt`
6. `通用模块/联动模块.md` → 按【联动规则】联合设计参数（互相配合，禁止独立选参；★ 无图：从剧本提取主要承载物/材质逐条设计进参数设计表，来源标 `文本:剧本描述`；通过【自检清单】）
7. 最后 → 遵守 `视频模块/基础格式.txt` 输出提示词文件，位置是单集文件夹

## 步骤4｜收尾

1. 无异常 → 不写任何文件，正常结束
2. 有异常（含 找不到剧本中对应的资产图）→ 按 `规范/异常设计.md` 写入 `异常/日期异常.md`
