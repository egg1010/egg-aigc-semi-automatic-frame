仅限视频模块操作
1初始化
{
    如果没有明确要求 每一集的每一段是多少秒
    {
        默认每一段是30秒
    } 
    如果在工作目录下有规范/项目规范
    {
        记忆项目规范 
    }
    如果在工作目录下有规范/多集要求
    {
        记忆多集要求
    }
    规范文件为空执行默认
    
    重点是记忆参数和规范 做出选择
    文件规范
    {
        在工作目录下有 对应的 可能是 xxx戏文件夹 可能是数字命名 里面有资产图 和剧情 最后 在对应 xxx戏文件夹内创建 提示词文件
    }
     
}


2进入单集文件夹 可能是xxx戏文件夹 可能是数字命名
{
    
    判断
    {
        如果没有图片
        {
            文本模式    
        }
        如果有
        {
            如果没有输入图片分析限制
            {
                auto模式
            }
        }
    }

}

3运行
{
    通过模块 思考 设计参数 达到 画面要求
    
    图片模式
    {   
        部分模块在通用模块/xxx.txt
        确定     
            1 确认风格 没有默认写实 实拍风格 电影感 
            2 视频模块/图片分析限制模块 需要记忆 后续模块配合调整
            3 色彩模块
            4 光线模块
            5 材质模块
            6 皮肤模块
        最后 
            遵守 视频模块/基础格式.txt 输出 提示词文件 位置是单集文件夹
    }

    文本模式
    {
        部分模块在通用模块/xxx.txt
        确定 
            1 确认风格 没有默认写实 实拍风格 电影感 
            2 色彩模块
            3 光线模块
            4 材质模块
            5 皮肤模块
        最后 
            遵守 视频模块/基础格式.txt 输出 提示词文件 位置是单集文件夹
    }    
}

4收尾
{
    如果工作区没有异常文件夹 
    {
        新建异常文件夹
    }   
    如果有问题 
    {
       在异常文件夹 详细 描述 哪里有问题 
    }
    
    请注意 如果 没有找到剧本中对应的资产图 需要在工作区 下的 异常文件夹 详细 描述 哪里有问题  
}
