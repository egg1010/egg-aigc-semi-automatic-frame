
初始化
{
    在文件夹 搜索 规范/拆分格式规范 如果是空或没有 就 执行默认

    如果没有明确要求按照多少秒分段 
    {
        默认30秒 
        必须思考 x秒能否做到表演充分
    }    
    如果没有在文件夹下找到 格式和项目规范
    {  

        拆分内容格式
        {
            默认
            剧本原封不动 按照分段 写入对应的文件
        }
        默认
        拆分文件夹 格式
        {
            //x为集 a为分段
            int x=0;
            int a=0;
            文件路径 工作区文件下x/x-a  
            a++;
            x集分段完成
            {
                x++;   
            }
        } 
    }
}

收尾
{
    如果工作区没有异常文件夹 
    {
        新建异常文件夹
    }   
    如果有问题 
    {
       在异常文件夹 详细 描述 哪里有问题 
    }
}
