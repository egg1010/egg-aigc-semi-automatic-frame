# 文本拆分模块（TEXT SPLIT MODULE）

## 初始化

1. 优先阅读 `规范/自定义拆分格式规范.txt`（在文本拆分前）
   - 如果为空或不存在 → 执行 默认规则
   - 如果内容不合理（与流程冲突、路径规则无法执行、自相矛盾）→ 询问用户确认后再执行，不要凭猜测解析
2. 分段时长
   - 如果没有明确要求按照多少秒分段 → 默认 30秒
   - 必须思考：x秒能否做到表演充分——段内 台词+动作+情绪转折 必须完整表达；若固定秒数会切断表演（台词中途/动作中途/情绪转折处被切）→ 移动切分点到表演单元的自然边界，保证该秒数内表演充分
3. 如果没有在文件夹下找到 格式和项目规范 → 执行 默认规则

## 默认规则

1. 拆分内容格式：剧本原封不动，按照分段写入对应的文件
2. **分段依据（AI 理解分段）**：
   - 分段按 AI 对剧情的理解切分（剧情节奏、情绪转折、表演单元），保证每段表演充分
   - **不按照剧本或文本中的标号切分**（场景号、章节编号、字幕序号等仅作参考，不作为分段边界）
   - **分集与剧本保持一致**：每集的内容只写入该集的文件夹，不跨集合并、不跨集拆分；集内分段完全由 AI 理解决定
   - **上下衔接**：切分点选在表演单元的自然边界（动作完成／台词结束／情绪落点）；上一段的结束状态 = 下一段的起点（人物位置/道具状态/情绪连续），禁止在动作进行中或台词中途硬切；交界处剧情依赖上一段的 → 在分段文件结尾/开头保留衔接所需的最小原文（仍属剧本原封不动原则）
3. 拆分文件夹格式（伪代码：x为集，a为分段）

   ```text
   int x=0;
   int a=0;
   文件路径 = 工作区文件下 x/x-a
   a++;
   x集分段完成 → 在 x 文件夹内创建 资产图 子文件夹 → x++;
   ```
4. 资产文件夹：**每一集自动创建一个**（x/资产图），注意不是每个分段一个；用于存放该集资产图，供视频模块按集取用
5. **剧本逻辑检查（只查不改）**：拆分时同步检查剧本逻辑——因果矛盾／时间线冲突／人物状态跳变／道具凭空出现或消失／场景不连贯／对白与动作冲突：
   - ★ 禁止修改剧本（剧本为只读源，任何情况下不得改动原文）
   - 发现逻辑问题 → 直接触发异常：按 `规范/异常设计.md` 写入 `异常/日期异常.md`（位置/段号 + 问题一句话）
   - 存在逻辑问题 → **终止拆分**（不产出拆分文件，避免问题流入下游视频模块）；问题过于严重或数量多 → 询问用户后再定

## 收尾

1. 无异常 → 不写任何文件，正常结束
2. 有异常 → 按 `规范/异常设计.md` 写入 `异常/日期异常.md`
