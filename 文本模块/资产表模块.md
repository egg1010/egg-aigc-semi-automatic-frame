# 资产表模块（ASSET TABLE MODULE）

## 前置检查

- 如果项目文件夹下没有需要的资产文件夹
  → 在项目文件夹下新建需要的资产文件夹

## 分析规则

1. 阅读剧本 → 分析需要的场景
2. 阅读剧本 → 分析需要的**道具**（反复出现、剧情关键、特写涉及的道具）
   - **道具材质识别**：道具的一句话外观中必须写明表面材质与状态（例：青铜古镜-绿锈斑驳 / 军大衣-厚呢磨白起球 / 玻璃杯-透亮无水痕）——来源沿用 理解模块【MATERIAL MEMORY】的标注（剧本明写优先，推断可用），供资产图生成与后续 联动模块 材质行调用
3. 多个戏在同一个场景 → 不要重复
4. 同一人物有不同的服装 → 也要写入资产表

## 资产表格式（道具在资产表最下面）

```text
场景
    x1集 x2集 对应资产 简短起名
人物
    名字xxx 性别 大概服装
道具
    名字xxx 所属集 一句话外观
```
